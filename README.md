# calendar_u

Персональный календарь — одностраничное веб-приложение без бэкенда и зависимостей.

## Возможности

- **Три вида**: день, неделя, месяц
- **События**: название, дата, время, цвет (5 вариантов), категория (6 значений), место, описание, прикреплённые файлы (до 10)
- **Редактирование**: клик по карточке события открывает его для редактирования
- **Хранение**: `localStorage` (работает офлайн)
- **Экспорт**: JSON
- **Синхронизация**: автоматическая через GitHub Gist
- **Фильтр по категориям** в шапке
- **Настройки**: тема, первый день недели, выходные, формат времени
- **Адаптивность**: десктоп, планшет, мобильные
- **Тёмная тема**: поддержка `prefers-color-scheme`
- **Безопасность**: защита от XSS, prototype pollution, валидация ввода

## Запуск

Откройте `index.html` в браузере. Всё работает локально, сервер не нужен.

## Настройки

Нажмите на **шестерёнку** в шапке календаря:

- **Тема оформления**: системная, светлая, тёмная, сепия, океан, лесная
- **Первый день недели**: понедельник, воскресенье или суббота
- **Выходные**: какие дни считать выходными
- **Формат времени**: 24-часовой или 12-часовой (AM/PM)

Настройки сохраняются в `localStorage` и применяются автоматически.

## Синхронизация через GitHub Gist

Приложение может автоматически сохранять события в GitHub Gist и загружать их при открытии — это позволяет синхронизировать календарь между устройствами без бэкенда.

### Настройка

1. Создайте новый Gist на [gist.github.com](https://gist.github.com) (добавьте любой файл, например `calendar-events.json`).
2. Скопируйте Gist ID из URL — это строка после последнего `/`:
   ```
   https://gist.github.com/username/a1b2c3d4e5f6...
                            ^^^^^^^^^^^^^^^^^^^^
   ```
3. Создайте Personal Access Token с правами `gist` на [github.com/settings/tokens](https://github.com/settings/tokens).
4. В приложении нажмите кнопку **Gist** в шапке, вставьте Gist ID и токен, нажмите «Сохранить».

### Как это работает

- Токен и Gist ID хранятся только в `localStorage` вашего браузера.
- При каждом изменении событий автоматически выполняется загрузка в Gist (с задержкой 2 секунды).
- При открытии приложения события автоматически загружаются из Gist.
- Кнопка **Gist** становится зелёной, когда синхронизация настроена.
- Кнопка **Синхр.** позволяет вручную загрузить и выгрузить данные.

### Безопасность

- Токен имеет доступ только к Gist (scope `gist`).
- Не используйте один токен для нескольких человек — каждый участник создаёт свой Gist и токен.
- Для приватности сделайте Gist секретным (Secret Gist) — он не индексируется поисковиками.

## Структура данных

```json
[
  {
    "id": "ev...",
    "title": "Название события",
    "start": "2026-10-07T10:00:00",
    "end": "2026-10-07T11:00:00",
    "location": "Место",
    "description": "Описание",
    "category": "purple",
    "eventCategory": "Конкурс в Москве",
    "attachedFiles": [{ "name": "file.pdf", "dataUrl": "data:..." }]
  }
]
```

- `category` — цвет события: `purple`, `amber`, `pink`, `lavender`, `peach`.
- `eventCategory` — категория события: `Конкурс в Москве`, `Выездной конкурс`, `Внутреннее мероприятие`, `Выездное мероприятие`, `Постановка`, `Прочее`.
- `start`/`end` — локальное время без часового пояса; событие всегда отображается ровно так, как было введено при создании.

## Безопасность

- **XSS-защита**: весь пользовательский ввод экранируется при выводе в DOM
- **Prototype pollution**: объекты очищаются от опасных ключей (`__proto__`, `constructor`, `prototype`)
- **Валидация**: все поля проверяются и ограничиваются по длине
- **Белый список**: категории проверяются по допустимым значениям

## Технологии

- Чистый HTML/CSS/JavaScript, без фреймворков
- GitHub Gist API для синхронизации
- `localStorage` для локального хранения
