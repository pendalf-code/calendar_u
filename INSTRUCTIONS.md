# INSTRUCTIONS.md — Инструкции для разработки календаря

## Общие правила

1. **При изменении темы** — все CSS-переменные (`--bg`, `--surface`, `--border`, `--text`, `--text-muted`, `--c-*`) должны быть определены для каждой темы. Используйте `applySettings()` в JS для динамического применения.

2. **Скролл** — `body { overflow: hidden }` — глобального скролла быть не должно. Скролл допустим только внутри контейнеров с явно заданным `overflow` и ограниченной высотой. Временная сетка (день/неделя) — единый скролл-контейнер `.time-grid-wrapper` (`overflow: auto`): заголовок дней `.time-grid-header` приклеен (`position: sticky; top: 0`), столбцы `.time-grid-body` имеют естественную высоту. Заголовок и столбцы всегда одной ширины — отдельную синхронизацию скролла делать не нужно.

3. **Модальные окна** — закрытие по клику вне окна должно использовать `mousedown`, а НЕ `click`. Иначе окно закрывается при отпускании кнопки мыши за пределами модалки.

4. **События в сетке** — расчёт позиций `left` и `width` в процентах с небольшим px-зазором между пересекающимися событиями. Формула: `left = (col.x * (100 / col.total) + 1.5) + "%"`, `width = (100 / col.total - 3) + "%"`.

5. **Стрелки селектов** — `<select>` — замещаемый элемент, `::after` на нём не работает. Оборачивайте в `<div class="select-wrapper">` и рисуйте стрелку через псевдоэлемент обёртки.

6. **Иконки** — используйте inline SVG с `currentColor`, чтобы иконки наследовали цвет текста и адаптировались под тему. Не используйте Unicode-символы для иконок.

7. **Время событий** — создаётся ровно из указанных пользователем значений (`new Date(y, m-1, d, h, min)`), без перевода в локальное время. Хранение — локальный ISO без `Z` (`fmtLocalIso`/`parseLocalIso`). Строки с явным поясом (`Z`, `+03:00`) парсятся как абсолютное время.

## Проверки перед коммитом

- [ ] Светлая тема ≠ тёмная тема (визуально отличаются)
- [ ] Все темы (light, dark, sepia, ocean, forest) корректно отображают поля ввода
- [ ] Нет скролла на странице (`body { overflow: hidden }`)
- [ ] Модальные окна не закрываются при отпускании кнопки за пределами
- [ ] События в недельном и дневном режимах не выходят за рамки колонок
- [ ] Заголовки дней и вертикальные столбцы одинаковой ширины (единый скролл-контейнер)
- [ ] Стрелки селектов отображаются и видны на всех темах
- [ ] Адаптивность: на мобильных (320px+) всё читается и не ломается

## Темы оформления

| Тема | data-theme | Описание |
|------|------------|----------|
| Системная | — | Автоопределение по `prefers-color-scheme` |
| Светлая | — | Светлая палитра (по умолчанию) |
| Тёмная | — | Тёмная палитра |
| Сепия | `sepia` | Тёплая бежевая гамма |
| Океан | `ocean` | Холодная сине-бирюзовая гамма |
| Лесная | `forest` | Природная зелёная гамма |

## Структура проекта

Однофайловое приложение — весь код в `index.html`:
- CSS: в `<style>` (строки ~8–960)
- HTML: в `<body>` (строки ~962–1142)
- JS: в `<script>` (строки ~1144–2069)

## Основные функции

| Функция | Назначение |
|---------|------------|
| `applySettings()` | Применение темы и настроек к CSS |
| `render()` | Главный рендер (день/неделя/месяц) |
| `renderWeek()` | Рендер недельного вида |
| `renderDay()` | Рендер дневного вида |
| `renderMonth()` | Рендер месячного вида |
| `layoutEvents()` | Расчёт позиций пересекающихся событий |
| `eventsForDay()` | События дня с учётом фильтра по категориям |
| `saveEvents()` / `safeLoadEvents()` | Сохранение/безопасная загрузка в `localStorage` |
| `gistUpload()` / `gistDownload()` | Синхронизация с GitHub Gist |
| `openModal()` / `closeModal()` | Модалка создания/редактирования события |
| `fmtLocalIso()` / `parseLocalIso()` | Локальный ISO-формат времени |
| `validateEvent()` / `sanitizeObject()` | Валидация и очистка событий |
| `escapeHtml()` | Экранирование для DOM |

## Примечания

- У события два поля «категория»: `category` — цвет (5 значений), `eventCategory` — текстовая категория (6 значений, используется в фильтре шапки).
- Настройка `hourHeight` (высота часа, по умолчанию 56) есть в коде и влияет на масштаб сетки, но не имеет элемента управления в модалке настроек.
- Функция `loadEvents()` в коде не используется — загрузка идёт через `safeLoadEvents()`.
