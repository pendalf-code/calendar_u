# INSTRUCTIONS.md — Инструкции для разработки календаря

## Общие правила

1. **При изменении темы** — все CSS-переменные (`--bg`, `--surface`, `--border`, `--text`, `--text-muted`, `--c-*`) должны быть определены для каждой темы. Используйте `applySettings()` в JS для динамического применения.

2. **Скролл** — `body { overflow: hidden }` — глобального скролла быть не должно. Скролл допустим только внутри контейнеров с явно заданным `overflow-y: auto` и `max-height`.

3. **Модальные окна** — закрытие по клику вне окна должно использовать `mousedown`, а НЕ `click`. Иначе окно закрывается при отпускании кнопки мыши за пределами модалки.

4. **События в сетке** — расчёт позиций `left` и `width` должен быть в процентах БЕСЗ смещения на px. Формула: `left = (col.x * (100 / col.total)) + "%"`, `width = (100 / col.total) + "%"`.

5. **Стрелки селектов** — `<select>` — замещаемый элемент, `::after` на нём не работает. Оборачивайте в `<div class="select-wrapper">` и рисуйте стрелку через псевдоэлемент обёртки.

6. **Иконки** — используйте inline SVG с `currentColor`, чтобы иконки наследовали цвет текста и адаптировались под тему. Не используйте Unicode-символы для иконок.

## Проверки перед коммитом

- [ ] Светлая тема ≠ тёмная тема (визуально отличаются)
- [ ] Все темы (light, dark, sepia, ocean, forest) корректно отображают поля ввода
- [ ] Нет скролла на странице (`body { overflow: hidden }`)
- [ ] Модальные окна не закрываются при отпускании кнопки за пределами
- [ ] События в недельном и дневном режимах не выходят за рамки колонок
- [ ] Стрелки селектов отображаются и видны на всех темах
- [ ] Адаптивность: на мобильных (320px+) всё читается и не ломается

## Темы оформления

| Тема | data-theme | Описание |
|------|------------|----------|
| Системная | — | Автоопределение по `prefers-color-scheme` |
| Светлая | — | Светлая палитра (по умолчанию) |
| Тёмная | — | Тёмная палитра |
| Сепия | `sepia` | Тёплая бежевая гамма |
| Океан | `ocean` | Холодная сине-бирюзовая гамма |
| Лесная | `forest` | Природная зелёная гамма |

## Структура проекта

Однофайловое приложение — весь код в `index.html`:
- CSS: в `<style>` (строки ~9–850)
- HTML: в `<body>` (строки ~850–1050)
- JS: в `<script>` (строки ~1050–1800)

## Основные функции

| Функция | Назначение |
|---------|------------|
| `applySettings()` | Применение темы и настроек к CSS |
| `render()` | Главный рендер (день/неделя/месяц) |
| `renderWeek()` | Рендер недельного вида |
| `renderDay()` | Рендер дневного вида |
| `renderMonth()` | Рендер месячного вида |
| `layoutEvents()` | Расчёт позиций пересекающихся событий |
